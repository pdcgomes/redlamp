title: How components combine tag: Model caption: **Each component after the first changes the shape so far.** The circle is the mask so far and the dashed square the component being added; the tint is what the mask covers afterwards. Invert belongs to a single component. ---
Add

Covers what either covers: a sky, and a river below it.

Subtract

Takes away what the new one covers: a gradient, less a person in it.

Intersect

Keeps only what both cover: a gradient, only in the sky.

Invert

One component, turned inside out: everything but a face.
