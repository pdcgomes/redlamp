## Rules for the round

- **Rendering:** no agent changes how an existing edit renders. The process version is the orchestrator's. Gates lands first, so every later merge is checked by it.
- **The other sessions' areas** are off limits: removal (RM-*), the audit fixes (AUD-*), noise (DN-*), `video/` and `web/`.
- **Builds:** each agent builds only its scheme, with its own build directory (`/tmp/w1-<agent>-dd`), and runs targeted tests; one full suite at the end.
- **Merges:** the orchestrator verifies each branch's files against its owned paths, merges with `--no-ff`, runs the affected suites and the gate, updates the tracker row and syncs issues. Pushes wait for the owner.

## Decisions

- 2026-10-03: the owner approved the five agents and accepted LNS-04; pushes wait for the owner.
- 2026-10-03: embedded lens corrections take precedence over a user's LCP profile, as Lightroom uses a raw's built-in profile.
- 2026-10-03: log-space LUTs are converted into `sceneLog` tables at import, so the kernel doesn't change.
- 2026-10-03: Lens merged (0c8729c) with the orchestrator's wiring (45e252c, 62c8574): user profiles get their own `LensCorrection.Source.profile`, applied from process 5 like embedded corrections, and the engine reads them only when the app or CLI passes `LCPProfileLibrary.user`, so tests and the stability gate never see a developer's profiles.
- 2026-10-03: the orchestrator never amends or rewrites commits on `main`: other sessions commit to it at the same time (an amend once folded a fix into another session's commit; undone with a soft reset before anything was pushed).
- 2026-10-03: wrong-pixel bugs (NaN, black) are fixed in every process version, and a reference that recorded one is re-recorded in the same change (AGENTS.md).
- 2026-10-03: the sidecar format stays at 3 for the frame style: every sidecar carries the format version, so 4 would make every edit saved from now on read-only in 0.2.1 and older builds; pinning `FrameStyle`'s stored numbers removes the reordering risk instead.
- 2026-10-03: the Recipes panel lists the user's recipes by group, as the recipe format says (the owner kept Import's change); imported LUTs move to an "Imported" list.
- 2026-10-03: Crop merged before Gates (76de46a): it changes only the crop tool's UI, so it can't move a render; the gate checks the rendering branches after it lands.
